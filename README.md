📘 Java OOP Learning Repository

Welcome to my Java OOP Practice Repository!
This repo contains all my practice files, examples, and notes while learning Object-Oriented Programming (OOP) using Java.

✔️ 2. Encapsulation

✔️ 3. Inheritance

Parent & child classes

Code reuse

"extends" keyword usage


✔️ 4. Composition

“Has-A” relationship

Building complex objects from simpler ones


✔️ 5. Abstraction

Abstract classes

Abstract methods

Interfaces


✔️ 6. Polymorphism

Method overloading

Method overriding

Dynamic binding
